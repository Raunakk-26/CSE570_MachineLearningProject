# Model Evaluation

## Objective
Evaluate machine learning models for customer purchase prediction.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Model Comparison

Compare the performance of Logistic Regression,
Decision Tree and Random Forest.

## Evaluation Process

1. Generate predictions on test data.
2. Calculate evaluation metrics.
3. Analyse classification performance.
4. Identify strengths and limitations of each model.

## Conclusion

Model evaluation helps identify the most suitable
algorithm for predicting customer purchasing behaviour.
