# Exploratory Data Analysis (EDA)

## Objective
Understand customer purchasing behaviour and identify
patterns in e-commerce transaction data.

## Analysis Performed

1. Examine dataset dimensions and structure.
2. Analyse numerical features using descriptive statistics.
3. Identify missing values and duplicate records.
4. Examine distributions using histograms.
5. Detect outliers using boxplots.
6. Analyse relationships using correlation analysis.
7. Identify customer purchasing patterns.

## Visualisation Techniques

- Histograms for numerical distributions.
- Boxplots for outlier detection.
- Bar charts for categorical analysis.
- Heatmaps for correlation analysis.

## Expected Outcome

EDA helps identify important patterns, data quality
issues and useful features for machine learning.
