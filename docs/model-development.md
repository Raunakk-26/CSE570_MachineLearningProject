# Machine Learning Model Development

## Objective
Develop predictive models to analyse e-commerce
customer purchasing behaviour.

## Model Development Workflow

1. Select relevant features.
2. Split data into training and testing sets.
3. Train baseline machine learning models.
4. Compare model performance.

## Algorithms

- Logistic Regression
- Decision Tree
- Random Forest

## Model Evaluation
Evaluate models using accuracy, precision, recall,
F1-score and confusion matrices.

## Objective of Comparison
Identify a suitable model for predicting customer
purchasing behaviour.
